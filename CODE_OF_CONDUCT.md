# Code of Conduct

SimpliScribe adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in full, including its standards and enforcement guidelines. It applies to project issues, pull requests, code review, documentation, and other project spaces.

## Reporting a concern

Project maintainers will review conduct reports they receive and may remove content or restrict participation. For an issue, pull request, or comment, use GitHub's **Report content** control and select **Report to repository admins** when offered; this submits the report privately to repository maintainers. If that option is unavailable, use GitHub's [Report abuse form](https://github.com/contact/report-abuse). Do not put private or identifying details in a public issue.

For security or privacy vulnerabilities, use the private reporting route in [SECURITY.md](SECURITY.md). Do not use a public issue for either type of report.
