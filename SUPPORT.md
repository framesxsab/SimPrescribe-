# Support

- For general setup or workflow questions, start with the [README](README.md) and [CONTRIBUTING guide](CONTRIBUTING.md).
- For a reproducible software issue, use the [bug report form](https://github.com/framesxsab/SimPrescribe-/issues/new?template=bug_report.yml).
- For product or workflow suggestions, use the [feature request form](https://github.com/framesxsab/SimPrescribe-/issues/new?template=feature_request.yml).
- For vulnerabilities, use the private reporting instructions in [SECURITY.md](SECURITY.md), not a public issue.
- For a software behavior that raises a patient-safety concern, use the bug report form with a synthetic reproduction and no patient data. Maintainers do not provide clinical or emergency support; contact a qualified clinician or local emergency services for care.

Never post patient identifiers, prescription images, passwords, API keys, session cookies, or unsanitized logs. SimpliScribe does not provide medical advice or patient support.
